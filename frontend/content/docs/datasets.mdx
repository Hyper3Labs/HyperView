# Datasets

Learn how to create, manage, and persist datasets in HyperView.

## Creating a Dataset

```python
import hyperview as hv

# Persistent dataset (default) - survives restarts
dataset = hv.Dataset("my_dataset")

# In-memory dataset - lost when process exits
dataset = hv.Dataset("my_dataset", persist=False)
```

**Storage location:** `~/.hyperview/lancedb/` (configurable via `HYPERVIEW_DATABASE_DIR`)

## Adding Samples

### From HuggingFace

Load datasets directly from HuggingFace Hub:

```python
dataset.add_from_huggingface(
    "uoft-cs/cifar100",
    split="train",
    image_key="img",
    label_key="fine_label",
    max_samples=1000,
)
```

**Parameters:**
- `dataset_name`: HuggingFace dataset identifier
- `split`: Dataset split (e.g., "train", "test", "validation")
- `image_key`: Column name containing images (default: "img")
- `label_key`: Column name containing labels (default: "label")
- `max_samples`: Maximum number of samples to load (optional)

### From Directory

Load images from a local directory:

```python
dataset.add_images_dir("/path/to/images", label_from_folder=True)
```

**Parameters:**
- `path`: Path to directory containing images
- `label_from_folder`: Use parent folder name as label (default: False)

## Persistence Model: Additive

HyperView uses an **additive** persistence model to efficiently manage datasets:

| Action | Behavior |
|--------|----------|
| Add samples | New samples inserted, existing skipped by ID |
| Request fewer than exist | Existing samples preserved (no deletion) |
| Request more than exist | Only new samples added |
| Embeddings | Cached per-sample, reused across sessions |
| Projections | Recomputed when new samples added (UMAP requires refit) |

### Example

```python
dataset = hv.Dataset("my_dataset")

dataset.add_from_huggingface(..., max_samples=200)  # 200 samples
dataset.add_from_huggingface(..., max_samples=400)  # +200 new → 400 total
dataset.add_from_huggingface(..., max_samples=300)  # no change → 400 total
dataset.add_from_huggingface(..., max_samples=500)  # +100 new → 500 total
```

**Important:** Samples are **never implicitly deleted**. Use `hv.Dataset.delete("name")` for explicit removal.

## Computing Embeddings

### High-Dimensional Embeddings

Compute CLIP or ResNet embeddings for your samples:

```python
# High-dimensional embeddings (CLIP/ResNet)
dataset.compute_embeddings(model="clip", show_progress=True)
```

Embeddings are stored per-sample. If a sample already has embeddings, it's skipped to save computation.

### 2D Projections

Generate 2D projections for visualization:

```python
# 2D projections for visualization
dataset.compute_visualization()  # UMAP to Euclidean + Hyperbolic
```

This creates both:
- **Euclidean projection**: Standard 2D UMAP
- **Hyperbolic projection**: Poincaré disk embedding

## Managing Datasets

### List All Datasets

```python
# List all persistent datasets
datasets = hv.Dataset.list_datasets()
print(datasets)  # ['cifar100_demo', 'my_dataset', ...]
```

### Delete a Dataset

```python
# Delete a dataset permanently
hv.Dataset.delete("my_dataset")
```

**Warning:** This operation is irreversible. All samples, embeddings, and metadata will be removed.

### Check Existence

```python
# Check if a dataset exists
if hv.Dataset.exists("my_dataset"):
    dataset = hv.Dataset.load("my_dataset")
```

## Dataset Properties

Access dataset information and samples:

```python
# Number of samples
total = len(dataset)

# Dataset name
name = dataset.name

# Unique labels
labels = dataset.labels

# Iterate over samples
for sample in dataset.samples:
    print(sample.id, sample.label)

# Get sample by ID
sample = dataset[sample_id]
```

## Saving and Loading

### Save Dataset

Persist the dataset with all embeddings and metadata:

```python
# Save to file
dataset.save("my_dataset.json")
```

### Load Dataset

Load a previously saved dataset:

```python
# Load from file
dataset = hv.Dataset.load("my_dataset.json")
hv.launch(dataset)
```

## Best Practices

1. **Use Persistent Datasets**: For large datasets with expensive embeddings, use persistent storage to avoid recomputation.

2. **Incremental Loading**: Add samples incrementally rather than all at once to monitor progress and manage memory.

3. **Compute Embeddings Once**: Embeddings are cached per-sample. Compute them once and reuse across sessions.

4. **Regular Backups**: Save important datasets to JSON files for backup and portability.

5. **Clean Up**: Delete unused datasets to free up storage space.

## Configuration

Configure HyperView's storage location:

```bash
# Set custom database directory
export HYPERVIEW_DATABASE_DIR=/path/to/storage
```

Default location: `~/.hyperview/lancedb/`

## Sample Object

Each sample in a dataset has the following properties:

```python
sample.id          # Unique identifier
sample.image       # Image data or path
sample.label       # Label/class
sample.embedding   # High-dimensional embedding (if computed)
sample.position_2d # 2D coordinates (if projection computed)
```
